## Описание стратегий и фильтров

Все стратегии вынесены в отдельный файл `strategies.py`. Каждая функция документирована (docstring).

### Стратегии сортировки (функции-ключи)

- **`by_balance(account)`** – возвращает баланс счёта (число). Используется для сортировки по балансу.
- **`by_owner(account)`** – возвращает имя владельца (строка). Используется для сортировки по владельцу.
- **`key_owner_balance(account)`** – возвращает кортеж `(owner, balance)`. Позволяет сортировать сначала по владельцу, затем по балансу.

### Функции-фильтры (предикаты)

- **`filter_active(account)`** – возвращает `True`, если счёт активен (`is_active == True`).
- **`filter_vip_balance(account)`** – возвращает `True`, если баланс счёта >= 1 000 000.
- **`make_min_balance_filter(min_balance)`** – фабрика функций. Принимает порог `min_balance` и возвращает функцию-предикат, которая проверяет `balance >= min_balance`.

### Callable-стратегия (класс с `__call__`)

- **`FeeStrategy(percent)`** – класс, который применяет комиссию в процентах к балансу счёта. Пример использования: `fee = FeeStrategy(1.5)` – списывает 1.5% от баланса.

## Реализация коллекции

Класс `BankAccountCollection` (файл `collection.py`) дополнен методами:

- **`sort_by(key_func, reverse=False)`** – сортирует текущую коллекцию по переданной ключевой функции. Возвращает `self` (для цепочек).
- **`filter_by(predicate)`** – возвращает **новую** коллекцию, содержащую только элементы, для которых предикат вернул `True`.
- **`apply(func)`** – применяет функцию `func` к каждому элементу коллекции (модифицирует объекты). Возвращает `self`.

Эти методы позволяют строить цепочки операций.
