# Лабораторная работа №7. Консольное приложение

## 1. Цель работы
Объединить знания и наработки из лабораторных работ 1–6 в единое работающее консольное приложение. Реализовать трехуровневую архитектуру (CLI, Бизнес-логика, Данные), интерактивное меню пользователя, обработку пользовательских исключений, а также механизм сохранения и загрузки данных в формате JSON.

## 2. Структура проекта
Приложение разбито на логические модули для обеспечения слабой связности:
* `main.py` — точка входа в программу.
* `cli.py` — уровень представления (Presentation Layer). Отвечает за отрисовку меню, ввод данных пользователем и форматированный вывод. Не содержит бизнес-логики.
* `app.py` — уровень бизнес-логики (Business Logic Layer). Обрабатывает запросы от CLI, управляет коллекцией банковских счетов.
* `exceptions.py` — набор пользовательских исключений предметной области (ошибки дубликатов, ненайденных счетов).
* `storage.py` — уровень доступа к данным (Data Access Layer). Обеспечивает сериализацию/десериализацию объектов и работу с `accounts.json`.
* `lab06/`, `lab05/` — переиспользуемые модули из прошлых работ (модели счетов, коллекция, стратегии, валидаторы).

## 3. Описание CLI
Консольный интерфейс предоставляет циклическое меню со следующими функциями:
1. **Добавление счёта** (с выбором типа: обычный, кредитный, накопительный).
2. **Просмотр всех счетов** (с форматированным табличным выводом).
3. **Поиск счёта** по уникальному номеру.
4. **Удаление счёта** (требует подтверждения операции `y/n`).
5. **Пополнение баланса**.
6. **Фильтрация** (например, по диапазону баланса).
7. **Сортировка** (с выбором стратегии: по балансу или по владельцу).
8. **Начисление процентов** (для соответствующих типов счетов).
0. **Выход** (с автоматическим сохранением состояния).

**Особенности:**
* **Обработка ошибок:** Ввод букв вместо чисел или пустых строк перехватывается, программа не падает, а просит повторить ввод. Ошибки бизнес-логики (например, дубликат номера) перехватываются через кастомные исключения и выводятся в понятном виде.
* **Сохранение/Загрузка:** При старте программа автоматически пытается считать данные из `accounts.json`. При корректном выходе (пункт 0) данные сериализуются и сохраняются на диск.

*Сценарий 3: Сортировка счетов по балансу и владельцу через стратегию*
*Сценарий 4: Попытка удаления счета с подтверждением, выход из программы (сохранение)*
